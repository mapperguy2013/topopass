# Phase 9: Exam Mode and Readiness

Status: Complete and ready for a controlled learner beta

Phase 9 added a distinct, timed Exam Mode on top of the protected Phase 8 atlas
and existing route engine. It keeps guidance out of active attempts, scores
only after submission, gives evidence-based review, stores local history, and
shows a deliberately non-official readiness signal.

## Result and limits

Learners can select an exam task, complete a timed independent route attempt,
submit a locked route, receive deterministic scoring and review, retain local
attempt history, and view a readiness signal. This is practice-product beta
readiness, not an official TfL assessment, certification, pass prediction, or
final production sign-off.
